# Результаты опросов

На странице документа, справочника или урока администратор открывает
«Аналитика → Результаты опроса». Здесь показываются сводка и поимённые ответы
сотрудников; у анонимного опроса связь с человеком не раскрывается. При выборе
версии материала отображается опрос именно этой версии. При повторном открытии
аналитики результаты загружаются заново. В редакторе остаётся настройка опроса,
а результаты перенесены в аналитику материала.

В базе знаний откройте вкладку «Результаты опросов» (`/lms/surveys`). Она доступна
администраторам и сотрудникам с правом `enrollments.manage`. Обычный читатель
не получает доступ ни к странице, ни к API результатов.

Каталог содержит опросы из уроков, документов, справочников, версий материалов
и новостей, в том числе закрытые. Поиск по названию не учитывает регистр,
список разбит на страницы по 20 опросов; он не ограничен первыми 15 строками
общей аналитики обучения.

«Посмотреть результаты» раскрывает распределение выбранных вариантов,
количество и долю ответов, среднее и распределение по шкале, письменные ответы
и список работающих участников с датами прохождения. Имена у письменных ответов
показываются только для неанонимных опросов. В блоке «Ответы сотрудников»
можно найти человека по имени и раскрыть его ответы на каждый вопрос:
выбранные варианты, свой вариант, оценку и текст. Пропущенный вопрос отмечен
«Не ответил». Удалённый вариант помечается явно; его прежний текст восстановить
из сохранённых номеров вариантов нельзя. Анонимные ответы не связаны
с участниками: отдельный список участия не раскрывает, кто что ответил.
Сводка ответов включает сохранённые ответы бывших сотрудников; список участников
и счётчик каталога, как в существующей аналитике, показывают работающих.

API списка: `GET /api/analytics/learning/surveys?page=1&search=...`.
API сводки и участников: `GET /api/analytics/learning/surveys/{id}`.
Оба адреса используют существующее право управления обучением.
