# Поделиться учебным материалом

Кнопка «Поделиться» есть на страницах курса, урока, документа и справочника.
Она передаёт ссылку на материал. Авторизация и правила доступа к нему сохраняются;
публичная копия статьи и новые разрешения не создаются. По ссылке открывается
материал с версией, доступной конкретному получателю.

Внутри платформы выберите «В сообщениях платформы», найдите сотрудника или
существующий чат, при желании напишите комментарий и нажмите «Отправить материал».
Отправка выполняется только этой кнопкой; выбор получателя ничего не отправляет.
В сообщении появляется карточка материала, собранная сервером. Лента системных
уведомлений не предлагается как чат для отправки.

Telegram и WhatsApp открывают собственный выбор получателя с названием и ссылкой;
окончательную отправку выполняет пользователь во внешнем приложении.
Используются [кнопка Telegram](https://core.telegram.org/widgets/share) и
[Click to Chat WhatsApp](https://faq.whatsapp.com/5913398998672934).

«Битрикс24 — скопировать» копирует название и ссылку для вставки в чат нужного
портала Битрикс24. Прямое подключение к порталу не настраивается.
«Копировать ссылку» работает для любых других сервисов. «Другие приложения…»
показывается при поддержке системного Web Share API в браузере.
Если буфер обмена недоступен, ссылку можно выделить и скопировать вручную.

Ссылка использует адрес открытой платформы: адрес localhost доступен только
на той машине, где запущено приложение. Для коллег используется адрес
развёрнутой платформы.
